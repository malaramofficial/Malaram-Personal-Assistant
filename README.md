# Malaram Personal Assistant

माला राम जी के लिए Android personal assistant.

## वर्तमान सुविधाएँ

- Hindi voice input (hi-IN)
- Offline neural Hindi female voice using Sherpa-ONNX + Piper
- Voice: vits-piper-hi_IN-priyamvada-medium
- Hindi greeting with माला राम जी
- YouTube / WhatsApp / Chrome / Google / Settings खोलना
- Google voice search
- Accessibility Back / Home / Recent Apps
- Accessibility swipe up/down
- Local command history (last 50)
- Sensitive-action guard for payment, OTP, password, deletion, purchase
- GitHub Actions automatic debug APK build
