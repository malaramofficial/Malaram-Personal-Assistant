# Malaram Personal Assistant

माला राम जी के लिए Android personal assistant का शुरुआती full-upgrade foundation.

## अभी क्या है
- Hindi voice input (hi-IN)
- Hindi text-to-speech
- नाम से greeting
- YouTube / WhatsApp / Chrome / Google / Settings खोलना
- Android Accessibility Service foundation
- GitHub Actions से automatic debug APK build

## अगले चरण
1. Accessibility से स्क्रीन पढ़ना
2. Tap / long-press / swipe / back / type
3. Multi-step voice tasks
4. Confirmation layer for sensitive actions
5. Command history
6. Optional AI planner
7. Release signing

## APK
हर push पर GitHub Actions debug APK बनाकर artifact में रखेगा।
